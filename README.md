# Estúdio de Narração · A Liga

Aplicativo para narrar as 3 aulas da CVDentus para a A Liga Dental Education: o vídeo passa, o texto acompanha com destaque palavra por palavra, o aplicativo grava a voz já alinhada com o vídeo e exporta o MP3 pronto.

**Abrir:** https://kahuesouza.github.io/estudio-narracao-aliga/

Use o **Google Chrome** ou o **Microsoft Edge**, em um computador, e permita o uso do microfone quando o navegador pedir.

## Passo a passo

1. Clique em **Ligar microfone** e fale: o medidor no canto superior direito tem que mexer. Se quiser ouvir o som do vídeo enquanto grava, use **fone de ouvido**.
2. Escolha uma aula e clique em **Gravar esta aula**. Depois de uma contagem de 3 segundos o vídeo começa. Leia o texto no ritmo do **destaque azul**.
3. Quando aparecer o quadro amarelo **Silêncio**, fique quieto: é o próprio vídeo falando.
4. Pode gravar quantas vezes quiser. Cada tentativa vira um *take*; use **Ouvir** para conferir com o vídeo e **Usar este** para escolher o melhor.
5. Clique em **Exportar MP3** (ou **Exportar as 3 aulas**). Os arquivos são salvos na pasta Downloads:
   - `01_Diamante_CVD_narracao.mp3`
   - `02_Piezo_narracao.mp3`
   - `03_Corte_Seletivo_narracao.mp3`
6. **Envie os 3 MP3 de volta.**

O MP3 sai mono, 48 kHz, 192 kbps, com o volume nivelado e a mesma duração do vídeo, pronto para entrar no ponto zero da aula no editor.

## Observações

- As gravações ficam salvas só no navegador deste computador e nada é enviado pela internet. Exporte os MP3 antes de limpar os dados do navegador.
- Teclas: **Espaço** grava/para, **+** e **−** mudam o tamanho da letra, **F** ativa o modo foco.
- Para usar offline, baixe o repositório (Code → Download ZIP), descompacte e dê duplo clique em `ABRIR_ESTUDIO.bat`.
